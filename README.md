# KKAMT Online Medical Service Platform (Telemedicine Concept)

## Project Overview
KKAMT Online Medical Service Platform is a telemedicine-based web platform concept developed as a group project under the College of Arts, Media and Technology, Chiang Mai University.

This project was conducted in academic collaboration with Chiang Mai Ram Hospital. The objective was to design a practical and innovative digital solution to support students’ access to medical services.

The project focused on business concept development, system design, and service feasibility rather than advanced coding complexity.

## Project Background
- Academic collaboration between College of Arts, Media and Technology, Chiang Mai University and Chiang Mai Ram Hospital
- Group project for a university course
- AI tools were permitted in the development process
- Evaluation emphasized business idea, system logic, and feasibility

## Deployment
The system was deployed on a DigitalOcean cloud server and was accessible via a public IP address for real-world testing and demonstration purposes.

This allowed the team to:
- Configure server environment
- Deploy the web application online
- Test system accessibility outside localhost
- Experience basic cloud hosting and server management

The server was later discontinued due to resource and maintenance constraints after project completion.

## Project Concept
The platform was designed as an online medical service system (telemedicine model) that enables:
- Online appointment booking for 24/7 medical service
- Health consultation request submission
- Online prescriptions and follow-ups
- Administrative service management

The goal was to improve accessibility and convenience for university students.
